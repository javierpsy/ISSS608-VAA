1 Overview

In this exercise, we will be tackling Mini-case 1 of VAST Challenge 2026.

1.1 Background

TenantThread is a property technology company that uses AI-powered systems to manage tenant engagement and communication processes. During a confidential merger project known as Project HarborCrest, strict embargo controls were implemented to prevent sensitive information from being released before the official announcement.

However, confidential merger-related information was leaked through AI-assisted communication channels prior to the embargo deadline. This raised concerns about whether the release was caused by deliberate actions, abnormal agent behaviour, or failures in the automated compliance system.

This mini-challenge focuses on analysing communication logs, agent interactions, and environmental events to reconstruct the sequence of events leading to the embargo breach.

1.2 Objectives

This analysis aims to:

  1. Reconstruct the sequence of events leading to the inappropriate release of confidential merger information by identifying key actions, causal relationships, communication patterns, and decision points involved in the embargo breach.
  2. Examine the behaviours and interactions of the systems, agents, and individuals involved to understand how the release bypassed the embargo enforcement mechanisms.
  3. Compare the behaviours leading to the release against prior historical behaviours to identify abnormal or unusual patterns.
  4. Detect potential leading indicators and prior instances where agents or systems behaved differently from their expected behaviours.
  5. Identify whether similar behavioural patterns had previously occurred and investigate why earlier incidents did not result in noticeable intervention or corrective action.
  6. Evaluate whether the inappropriate release was primarily caused by deliberate actions, abnormal agent behaviour, or weaknesses within the automated compliance and communication systems.

The engineered features are designed to support temporal, behavioural, and network-based visual analytics.

3.1 Engineering Temporal Communication Features

To reconstruct how the embargo breach unfolded, additional time-based variables were engineered from the original communication timestamps. These variables support event sequencing, communication timeline analysis, and identification of activity patterns before the inappropriate release.

Code 
communications_clean <- communications %>%
  mutate(
    timestamp = ymd_hms(timestamp),
    round_hour = ymd_hms(round_hour),

    communication_date = as_date(timestamp),
    communication_hour = hour(timestamp),
    communication_day = wday(timestamp, label = TRUE),

    communication_period = case_when(
      communication_hour >= 6 & communication_hour < 12 ~ "Morning",
      communication_hour >= 12 & communication_hour < 18 ~ "Afternoon",
      communication_hour >= 18 & communication_hour < 24 ~ "Evening",
      TRUE ~ "Late Night"
    ),

    days_before_embargo_breach =
      as.numeric(as_date("2046-06-05") - communication_date),

    near_breach_window = case_when(
      days_before_embargo_breach <= 2 ~ "Critical Period",
      days_before_embargo_breach <= 5 ~ "Escalation Period",
      TRUE ~ "Normal Period"
    ),

    message_sequence = row_number()
  )

3.3 Engineering Embargo and Merger-related Communication Indicators

To support downstream behavioural and anomaly analysis, further text-based indicators were developed to pinpoint communication records possibly linked to merger talks, embargo-related issues, and governance risks.

Keyword-based indicators were created to identify mentions concerning Project HarborCrest, CivicLoom, enforcement of embargoes, discussions on compliance, and potential information leakage behaviour.

Code 
communications_clean <- communications_clean %>%
  mutate(
    content_lower = str_to_lower(content),

    contains_project_terms = str_detect(
      content_lower,
      "harborcrest|civicloom|merger|rebrand|capital|deal"
    ),

    contains_embargo_terms = str_detect(
      content_lower,
      "embargo|judge|compliance|approved|blocked|deadline"
    ),

    contains_public_exposure_terms = str_detect(
      content_lower,
      "public|post|fle?x|release|leak|disclose|announcement"
    ),

    contains_pressure_terms = str_detect(
      content_lower,
      "pressure|urgent|concern|risk|legal|scrutiny|journal|algorithmiceviction"
    ),

    message_length = str_length(content),
    word_count = str_count(content, "\\S+"),

    risk_signal_score =
      as.integer(contains_project_terms) +
      as.integer(contains_embargo_terms) +
      as.integer(contains_public_exposure_terms) +
      as.integer(contains_pressure_terms),

    risk_signal_group = case_when(
      risk_signal_score >= 3 ~ "High Signal",
      risk_signal_score == 2 ~ "Moderate Signal",
      risk_signal_score == 1 ~ "Low Signal",
      TRUE ~ "No Signal"
)
  )
